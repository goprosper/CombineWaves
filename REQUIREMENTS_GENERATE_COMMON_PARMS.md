# Requirements: Generate Common Parms (Step 4)

## Overview

Generate a `CommonParms.csv` file that documents all common questions and their answers in the standard parms file format. This file serves as a reference for the combined survey data.

## Functional Requirements

### FR-1: Input Processing
- **FR-1.1**: Read `CommonQuestions.csv` generated by Step 2
- **FR-1.2**: Skip the header row (row 1)
- **FR-1.3**: Process each data row (rows 2+)

### FR-2: Question Number Assignment
- **FR-2.1**: Assign sequential question_number starting from 1
- **FR-2.2**: question_number = row_index - 1 (where row_index is 1-based)

### FR-3: Answer Count
- **FR-3.1**: Count elements in common_answer_ids (^-delimited)
- **FR-3.2**: Empty common_answer_ids results in total_answers = 0

### FR-4: Question Text Retrieval
- **FR-4.1**: Query `br_question_master` table for each question
- **FR-4.2**: Use study_name from control file (first entry)
- **FR-4.3**: Match on question_id = common_question_id
- **FR-4.4**: Retrieve `alternate_text` column for question_text

### FR-5: Answer Text Transformation
- **FR-5.1**: Query `br_question_master` for `answer_text` field
- **FR-5.2**: Parse answer_text as ^-delimited list (answer_text_map)
- **FR-5.3**: For each common_answer_id, look up answer_text_map[common_answer_id]
- **FR-5.4**: Produce ^-delimited answer_text_list

### FR-6: Question Type
- **FR-6.1**: Use ParmsQuestionType from CommonQuestions.csv

### FR-7: Output Format
- **FR-7.1**: Generate CSV file named `CommonParms.csv`
- **FR-7.2**: No header row (data only, matching standard parms format)
- **FR-7.3**: Column layout:
  - Column 1: question_number (integer)
  - Column 2: total_answers (integer)
  - Column 3: question_text (string)
  - Column 4: empty (blank)
  - Column 5: answer_text_list (^-delimited)
  - Column 6: question_type (single character: S, M, or F)

## Non-Functional Requirements

### NFR-1: Error Handling
- **NFR-1.1**: Log warning if question_id not found in br_question_master
- **NFR-1.2**: Use master_question_text from CommonQuestions.csv as fallback
- **NFR-1.3**: Continue processing on individual row failures

### NFR-2: Performance
- **NFR-2.1**: Process all rows in a single database session

### NFR-3: Integration
- **NFR-3.1**: Execute as Step 4 in combinewaves.py workflow
- **NFR-3.2**: Run after Step 3 (generate_common_pip)
- **NFR-3.3**: Report file creation in execution report

## Dependencies

- `CommonQuestions.csv` must exist (generated by Step 2)
- Database access to `br_question_master` table
- Control file must have at least one entry (for study_name)
